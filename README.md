
# HTML Forms Practice

A collection of HTML and CSS exercises focused on creating and styling web forms.

## Technologies Used

- HTML5
- CSS3
- Git & GitHub

## Projects

### 1. HTML Form — Basic

**Directory:** `html-form-task/`

Practice working with HTML form elements and basic page structure.

### 2. HTML Form — Advanced

**Directory:** `html-form-task-2/`

An extended form exercise covering different types of user inputs:

- Text input fields
- Radio buttons
- Checkboxes
- File uploads
- Dropdown menus and multiple selection
- Form layout and styling

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/labkramar-jpg/html-forms-practice.git
   ```

2. Open either project directory.
3. Open its HTML file in a web browser.

No additional dependencies are required.

## Learning Objectives

- Understand HTML document structure
- Build forms using different input types
- Apply CSS styling
- Work with form attributes and user interactions
- Improve page layout and usability
